# 中秋代码雨祝福

纯静态中秋祝福页：手机竖屏时以纯黑背景铺满可视区域，持续落下「中秋快乐」字符，中央用发光点阵依次呈现祝福。包含原版和家人版两个入口；只使用 HTML、CSS、原生 JavaScript 和 Canvas，无依赖、构建流程、接口或后端。

线上页面：[中秋代码雨祝福](https://hvili.github.io/i-love-you-wyy/)

家人版：[中秋代码雨祝福（家人版）](https://hvili.github.io/i-love-you-wyy/family.html)

## 本地预览

在项目目录启动静态服务器：

```powershell
python -m http.server 8080
```

原版打开 <http://localhost:8080/>，家人版打开 <http://localhost:8080/family.html>。按 `Ctrl+C` 停止服务器。不要用 `file://` 直接打开。

在安装了 Chrome 或 Edge 的 Windows 电脑上，可以运行 `node run_verify.js` 验证原版，或运行 `node run_verify.js /family.html` 验证家人版。脚本会检查整段文案、可视粒子与代码雨、浏览器控制台、隐藏页面暂停/恢复、最后一句停留，以及 390×844、横屏和桌面布局。截图与报告会写入 `test_output/`。

## 文案与节奏

`script.js` 顶部的 `MESSAGE_SETS` 保存两版祝福顺序。原版页面沿用原有文案；家人版依次显示「花好月圆、阖家团圆、身体健康、幸福美满、金玉满堂、心想事成、万事如意、平安喜乐、阖家欢乐、中秋快乐」。两版共用相同的点阵动画、代码雨与播放节奏，最后一句保留在画面上，代码雨继续运行。

## 可选音乐

把你提供的 MP3 放到 `assets/music.mp3`，并将 `script.js` 中的 `MUSIC_ENABLED` 改为 `true`。此时右上角会显示简洁的播放开关；默认关闭时不会请求音乐文件，按钮隐藏，动画照常运行。音乐只在点击开关后播放，以适配 iOS 与微信浏览器的播放限制。项目不附带音乐。

## 发布到 GitHub Pages

将 `index.html`、`style.css`、`script.js`、`assets/` 和 README 放在仓库根目录，然后在仓库的 **Settings → Pages** 选择从分支发布，选择主分支和 `/(root)`。页面资源使用相对路径，可发布在 GitHub 项目子路径下。

## 兼容与性能

- 手机竖屏按实际可视视口铺满屏幕；横屏和桌面会按 16:9 比例适配。
- 竖屏中较长的「让它替我去长沙看看你」视觉上分为两行，完整文案与无障碍朗读内容保持原句。
- 粒子文字画布的 DPR 上限为 2；高像素竖屏的雨幕画布降至 1.75 以控制全屏绘制负载。祝福目标点仅在切换文案或视口变化时采样。
- 页面进入后台时暂停动画帧；返回前台后继续播放。
- `test_output/` 是本地验收截图目录，不属于发布内容。
