# 中秋代码雨祝福

纯静态中秋祝福页：黑色竖屏留白，中间 16:9 画幅持续落下「中秋快乐」字符，中央用发光点阵依次呈现祝福。只使用 HTML、CSS、原生 JavaScript 和 Canvas，无依赖、构建流程、接口或后端。

## 本地预览

在项目目录启动静态服务器：

```powershell
python -m http.server 8080
```

打开 <http://localhost:8080>。按 `Ctrl+C` 停止服务器。不要用 `file://` 直接打开。

在安装了 Chrome 或 Edge 的 Windows 电脑上，也可以运行 `node run_verify.js` 自动检查整段文案、可视粒子与代码雨、浏览器控制台、隐藏页面暂停/恢复，以及 390×844、横屏和桌面布局。截图与报告会写入 `test_output/`。

## 文案与节奏

`script.js` 顶部的 `messages` 数组保存展示顺序。普通祝福约 1 秒聚合、停留约 2 秒、再用约 0.9 秒散开；「少了一个你」「让它替我去长沙看看你」「我有多想你」和「中秋快乐 ♡」停留约 3 秒。最后一句保留在画面上，代码雨继续运行。

## 可选音乐

把你提供的 MP3 放到 `assets/music.mp3`，并将 `script.js` 中的 `MUSIC_ENABLED` 改为 `true`。此时右上角会显示简洁的播放开关；默认关闭时不会请求音乐文件，按钮隐藏，动画照常运行。音乐只在点击开关后播放，以适配 iOS 与微信浏览器的播放限制。项目不附带音乐。

## 发布到 GitHub Pages

将 `index.html`、`style.css`、`script.js`、`assets/` 和 README 放在仓库根目录，然后在仓库的 **Settings → Pages** 选择从分支发布，选择主分支和 `/(root)`。页面资源使用相对路径，可发布在 GitHub 项目子路径下。

## 兼容与性能

- 手机竖屏中保留参考图的横向画幅和上下纯黑留白；横屏和桌面会按 16:9 比例适配。
- 两张画布按设备像素比绘制，DPR 上限为 2。祝福目标点仅在切换文案或视口变化时采样。
- 页面进入后台时暂停动画帧；返回前台后继续播放。
- `test_output/` 是本地验收截图目录，不属于发布内容。
